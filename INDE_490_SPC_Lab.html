Is the inspection process stable?

Equations & a calculation hint

Work in decimal proportions first. Multiply the final values by 100 for the percentage fields below.

p̄ = total failed ÷ total inspected

σp = √[p̄(1 − p̄) ÷ 100]

CL = p̄   ·   UCL = p̄ + 3σp

LCL = max(0, p̄ − 3σp)

A negative percentage is impossible, so set a negative lower limit to zero. Count each failed clip once, even if it has several defects.

Enter percentages: 6 means 6%. Round to two decimal places.

This short reference dataset is for learning. In practice, use more historical samples and assess their stability before adopting limits.
